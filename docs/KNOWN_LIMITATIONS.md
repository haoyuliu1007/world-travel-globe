# 已知工程限制与科学计算边界声明 (Known Limitations)

本文档以工程诚实为原则，明确说明 World Travel Globe V4.5.0 在计算精度、遥感数据源、浏览器图形渲染及硬件实测覆盖方面的真实边界。

---

## 一、摄影光学与三维地形模拟边界

1. **WebGL 垂直视场角限制 (`18°–65°`)**：
   - MapLibre GL JS v5 地球视口将渲染相机的垂直视场角（FOV）限制在 `18°–65°` 区间内。
   - **长焦端（等效 > 75mm，如 200mm / 400mm / 600mm）**：3D 取景器保持 `18°` 渲染下限，并通过精确的正切比缩放中心裁切框（Optical Crop）模拟对应视角范围，而非直接压缩 WebGL 相机光学投影。
   - **超广角端（如 14mm）**：受 `65°` 上限限制，视口外围透视畸变无法完全等效真实超广角物理镜头。
   - **画面要素差异**：WebGL 渲染场景不包含真实光学镜头的景深虚化、暗角、色散与光学畸变。

2. **DEM 高程网格分辨率与遮挡盲区**：
   - 前端 360° 山体遮挡射线追踪使用 AWS Terrarium DEM 的 `z12` 近场（约 38 m/px）与 `z11` 远场（约 76 m/px）栅格高程，视觉 3D 地形使用 Mapterhorn 512px WebP 主源（单瓦片出错自动回退 AWS Terrarium）。
   - 该分辨率适用于宏观山体地形遮挡估算，**无法识别城市建筑、树木、电线杆或地形局部微小凹凸**；计算结果仅代表基于公开栅格 DEM 与标准大气折射假设（`k ≈ 1.15`）的参考值，不构成野外安全或极端气候出行保证。

---

## 二、时区、气象与第三方公开数据源限制

1. **时区查询边界**：
   - 基于 `tz-lookup`（CC0）离线获取经纬度对应的 IANA 时区，并通过浏览器原生 `Intl.DateTimeFormat` 按所选目标日期计算真实 UTC 偏移及夏令时（如加德满都 `UTC+5:45`、阿德莱德 `UTC+9:30/+10:30`）。
   - 若坐标位于公海或国际领海边界未归属区而无法匹配陆地 IANA 多边形，系统将显式回退为 **经度估算（标示为 `Est. UTC±X`）**，不再使用当前天气接口返回的瞬时 `utc_offset_seconds` 替代任意历史/未来日期。

2. **第三方开放 API 可用性与限流**：
   - 包括 Open-Meteo、NASA GIBS/EPIC、NOAA SWPC、Wikimedia Commons、Wikidata、Panoramax、Mapterhorn、AWS Terrarium、OpenFreeMap 与 OSRM 在内的 11 路数据源均依赖上游服务实时配额与网络连通性。
   - `ApiClient` 已配备 `Retry-After` 指数退避、超时取消与 11 路健康状态追踪；当某一路不可用时界面展示诚实的降级/离线提示，**严禁生成伪造气象实况、伪造路网或虚构图像**。
   - Open-Meteo 5 年气候图表来自 ERA5 再分析网格数据（区域平均估计），山地微气候和单点气象站实测仍可能与网格统计存在明显差异。

---

## 三、设备兼容性与实测范围说明

1. **端到端测试环境范围**：
   - 本版本的自动化端到端测试运行于本机无头桌面 **Chromium (`playwright-core`)**，并通过预设视口（`360×800`、`390×844`、`768×1024`、`1440×900`）模拟移动端与平板端尺寸。
   - **尚未直接覆盖项目**：真机 iOS Safari 与真机 Android Chrome 的长期压测、实际 GPU 显存压力、多指复杂触控手势冲突与真机低电量热降频表现，需以物理真机实测为准；报告中不得将仿真视口结果混淆为物理真机实测。

2. **无 WebGL 环境的降级体验**：
   - 若设备禁用 GPU 硬件加速或 WebGL 上下文无法恢复，系统自动切换至「2D 图鉴与左侧目录清单」，确保全部 722 座目的地数据、机位信息与物候曲线仍可正常浏览，但不提供 3D 球体旋转、地形挤压与第一人称 3D 取景器功能。
